## 搬瓦工迪拜机房测评：线路分析

三网回程路由都走普通线路，没有任何对国内的优化：

- **电信**：电信163普通骨干
- **联通**：联通AS4837普通线路

迪拜本地访问则是另一回事。机房就在迪拜，Equinix 数据中心，对本地用户延迟极低，SpeedTest 可以跑满 1Gbps 带宽。对阿联酋境内用户，体验完全不同。
